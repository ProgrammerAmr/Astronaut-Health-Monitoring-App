## Description
This dataset includes summary-level blood pressure data (systolic, diastolic, mean arterial pressure) collected from peer-reviewed studies and the NASA Longitudinal Study of Astronaut Health (LSDA) on real and simulated spaceflight missions. Variables include mission type, sex, BMI, age, and countermeasure usage. The dataset supports the abstract submitted to the American Heart Association Hypertension 2025 Conference.

## File Contents
- `Cleaned_Numeric_BP_Dataset.csv`: Main data file with aggregated BP and demographic data
- `BP_Data_Dictionary.xlsx`: Definitions of all variables and units
- `README.txt`: This file

## Usage
This dataset may be used for academic, non-commercial purposes under the CC BY 4.0 license. Researchers are encouraged to cite the dataset using the DOI provided by Mendeley Data. Summary statistics were analyzed using Welch’s ANOVA and Games-Howell post-hoc tests.

## Data Source and Processing
- Source data: NASA LSDA (summary access), PubMed-indexed publications
- Inclusion criteria: Studies reporting at least one of SBP, DBP, or MAP in a spaceflight or spaceflight analog condition
- Standardization: Units harmonized to mmHg; demographics grouped by sex and BMI when available
